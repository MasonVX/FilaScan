FilaMan integration

Choose a regular FilaMan storage location before adding a new spool, or press an existing spool's location button to move it. Bambu AMS locations are excluded. The Tray UID is used as external_id; the NFC Tag UID is never transmitted.

HTTP is supported for trusted local networks but sends the device token and spool data without transport encryption.

The FilaScan integration plugin must be installed in FilaMan and authorize this registered device. General inventory scopes are not required.

Optional for HTTP. For HTTPS, use the CA certificate that issued the certificate for your FilaMan hostname.
