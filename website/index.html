Install FilaScan

Read Bambu Lab and OpenPrintTag filament spools with a standalone RFID reader.

Connect your reader

For WT32-SC01 Plus · ESP32-S3 · 16 MB flash with a PN532 or PN5180 reader. Other ESP32-S3 boards are not supported, even if the installer can connect to them.

  1. Connect the display to your computer using a USB data cable.
  2. Close serial monitors and other applications using this USB port.
  3. Click Connect, select the device, then choose Install FilaScan.

Keep settings or start fresh

The installer asks whether to Erase device. Leave this unchecked to keep settings (the default).

Keep settings — install or repair
Preserves saved Wi-Fi settings on existing FilaScan installations with the current partition layout. Firmware and boot selection are replaced. Settings from other firmware or older partition layouts cannot be guaranteed; use a fresh installation for those devices.
Fresh installation — check “Erase device”
Erases the internal flash, including saved Wi-Fi settings, before installing. You will be asked to confirm.

Both options leave the SD card untouched. FilaMan authentication tokens, settings, caches and pending offline operations on that card remain stored. Erasing the device does not unregister it from FilaMan.

After installation

The device restarts. If it cannot connect to Wi-Fi, wait 60 seconds for the setup access point and follow the instructions on its display. Future firmware updates can be installed over Wi-Fi from the display or the protected web interface.

Device not found or unable to connect?

Try a different USB data cable or port. If necessary, put the board in download mode using its BOOT/RESET controls, then reconnect. Check the hardware and USB instructions. This installer does not require FilaScan to be installed beforehand.
